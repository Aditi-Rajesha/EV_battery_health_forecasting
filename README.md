# 🔋 EV Battery Health Degradation Forecasting

## 📌 Overview
This project predicts the health degradation of Electric Vehicle (EV) batteries using Machine Learning techniques. It analyzes battery parameters to estimate future battery health and degradation trends, helping improve maintenance planning and battery life management.

---

## 🚀 Features

- Data Preprocessing
- Missing Value Handling
- Feature Engineering
- Model Training
- Model Evaluation
- Battery Health Prediction
- Visualization
- Explainable AI (SHAP)
